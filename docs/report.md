
# Практикалық жұмыс

## Тақырыбы

Amazon EC2 инстанстарында қашықтан командаларды орындау үшін
AWS Systems Manager пайдалану.

## Жұмыстың мақсаты

AWS Systems Manager Run Command құралын пайдаланып,
EC2 виртуалды серверінде қашықтағы командаларды орындауды үйрену.

## Орындалу барысы

1. GitHub-та жоба репозиторийі құрылды.
2. Amazon EC2 Linux инстансын дайындау жоспарланды.
3. Systems Manager үшін IAM рөлін баптау қарастырылды.
4. Қашықтан диагностикалау скрипті жасалды.
5. Run Command арқылы скрипт командаларын орындау жоспарланды.
6. Командалардың нәтижелерін тексеру қарастырылды.

## Нәтиже

Бұл бөлімге AWS Systems Manager арқылы командаларды сәтті
орындағаннан кейінгі скриншоттар мен нақты нәтижелер енгізіледі.

## Қорытынды

Жұмыс барысында AWS Systems Manager көмегімен EC2 инстанстарын
қашықтан басқару принциптері қарастырылды. Run Command құралы
серверде командаларды тікелей SSH байланысынсыз орындауға мүмкіндік береді.
